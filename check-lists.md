Checklist — Модуль авторизации

Интерфейс
* Отображается логотип компании
* Отображается поле логина
* Отображается поле пароля
* Отображается кнопка “Войти”
* Отображается ссылка “Забыли пароль?”
* Все элементы выровнены корректно
* Отсутствуют визуальные дефекты
Валидация полей
* Поле логина обязательно для заполнения
* Поле пароля обязательно для заполнения
* Проверяется формат email
* Проверяется минимальная длина пароля
* Проверяется максимальная длина пароля
* Отображаются сообщения об ошибках
Авторизация
* Успешный вход с валидными данными
* Ошибка при неверном пароле
* Ошибка при несуществующем пользователе
* Ошибка при пустых полях
* Проверена работа кнопки Enter
Безопасность
* Пароль скрыт символами маскирования
* Работает отображение пароля
* Проверена защита от SQL-инъекций
* Проверена защита от XSS
* Проверено ограничение попыток входа
Сессия
* Создается пользовательская сессия
* Пользователь остается авторизованным после обновления страницы
* После выхода из системы доступ закрывается
* Старый токен становится недействительным
API
* Запрос авторизации возвращает 200 OK
* Неверные данные возвращают ошибку
* Ответ приходит в корректном JSON
* В ответе отсутствуют чувствительные данные
